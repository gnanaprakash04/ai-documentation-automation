# LACP Pass-Through

## Overview

LACP pass-through allows LACP frames to be transparently transmitted
across the wireless link.

## Configuration

By default, LACP Pass-Through is disabled.

To enable LACP Pass-Through:

1. Go to **Network > Advanced**.
2. Locate **LACP Pass-Through**.
3. Enable the feature.
4. Click **Save**.

## Notes

The feature requires compatible network devices on both ends of the
wireless link.
